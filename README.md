IntroductionThe Hospital Management System is a Java-based console application developed as part of a Data Structures and Algorithms (DSA) course. It focuses on algorithmic thinking, efficient data handling, and scheduling mechanisms using core data structures rather than commercial graphical interfaces.ObjectivesTo implement real-world applications of Data Structures like trees, queues, and lists.To understand priority-based patient scheduling.To integrate DSA concepts with Object-Oriented Programming to build a modular system.Core FeaturesPatient & Doctor Management: Efficient handling and retrieval of hospital staff and patient records.Appointment Handling: Linking patients and doctors through data traversal.Priority-Based Scheduling: Managing patient queues based on emergency (high priority) versus normal (lower priority) cases.Data Structures & AlgorithmsAVL Tree: A self-balancing binary search tree used to store and manage records requiring fast searching, guaranteeing O(log n) time complexity.Circular / Priority Queue: Implemented for patient scheduling to ensure continuous queue rotation and that high-priority patients are treated first.Lists (ArrayList): Used dynamically for linear searches and sorting operations across patients, doctors, and appointments.Sorting (Bubble Sort): A comparison-based algorithm used to sort patient and doctor records based on specific attributes.Searching: Combines logarithmic search (via AVL Trees) and linear search (via Lists).System ArchitectureThe project follows a modular, layered architecture:Controller: Handles system logic, scheduling, and integrates core DSA concepts.Model: Represents real-world OOP entities like Person, Patient, Doctor, and Appointment.View: Manages interaction through a console-based menu.Exceptions: Custom error handling, including InvalidInputException and DatabaseException.Database UsageThe database is strictly used for data persistence.
